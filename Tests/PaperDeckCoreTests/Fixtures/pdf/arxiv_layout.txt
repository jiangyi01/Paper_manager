A Synthetic Benchmark for Evaluating Coding Agents on Biology Tasks
Ada Lovelace 1 Grace Hopper 2
arXiv:2606.24530v2 [cs.CL] 6 Jul 2026
Abstract
We introduce a synthetic benchmark of ninety tasks distilled from published papers and
evaluate six coding agents on it. The best agent solves 41% of the benchmark tasks.
1 Introduction
Coding agents are increasingly used for research. Existing benchmark suites focus on
software engineering (Figure 1), so we build a benchmark grounded in biology papers.2 Related Work
