## 1. AI 查重：新论文和你的「阅读历史」比一遍

**你会看到**：拖进一篇论文，如果它和库里已有的（待读、在读、已读、最近删除，甚至 30 天前彻底删掉、但你读过的）是同一篇或同一工作的另一个版本，卡片上出现「可能重复？」标签并弹出决策框，说明原因，例如：

> 「这是 bioRxiv v2 → 正式发表于 Nature 2026 的版本；你 5 月读过 v1（清单 7/7 已完成）。」

**四个选项**：
1. **保留新的**：换成新文件；清单、笔记、阅读历史全部保留；标题、DOI、期刊更新成新版本的（顺带修掉现在「替换后仍保留预印本 DOI」的 bug）。
2. **重读旧的**：旧的那篇移回「待读」；清单可选「保留进度 / 全部取消勾选 / 按新版本重新生成」；重新排 DDL。
3. **两篇都留**：记住「它们不是重复」，以后不再问。
4. **跳过**：不加。

批量拖文件夹时只弹一张汇总表，可「全部按建议处理」。另有「检查整个库的重复」，扫描结果给你逐组确认，**从不自动删除或合并**。

**怎么判断**（由快到慢，越往后用得越少）：
1. 文件哈希（已有）。
2. 标识符：DOI/arXiv/bioRxiv（已有）+ 新增 Crossref「预印本 ↔ 正式版」反向链接、arXiv 期刊 DOI、OpenAlex 作品 ID、eLife/F1000 等「版本号写在 DOI 里」的归并。
3. 标题 + 第一作者 + 年份模糊匹配 + 本机正文指纹（几毫秒），并有**硬性否决**：BRCA1 vs BRCA2、Part I/II、勘误、评论与回复、**补充材料 PDF**（`mmc1.pdf`、`*_MOESM*` 常印着主文 DOI，现在的「替换」按钮会把主文换成补充材料——这个隐患一并修掉）。
4. 本机语义相似度（Apple 自带句向量，不联网、不耗额度）——先做成可选，用你自己的库测过效果再默认打开。
5. **可选 AI 判定**：只有你打开开关才用，只看最可疑的 1–3 篇，小模型，每天上限 10 次；AI 只能把「可能」升降级，**不能自己替换或删除任何东西**；可能未发表的稿件（他人邮件发来的）永不送 AI。

## 2. 多选论文（「选取多少篇」）

我的理解（请确认）：**一次选中 N 篇论文，做批量操作或一起提问**。
- ⌘ 点击、⇧ 连选、⌘A 全选，以及「选择」菜单：最近添加的 N 篇 / 最早的 N 篇未读 / 最近打开的 N 篇。
- 选中后底部出现批量操作条：状态、优先级、分类、标签、DDL、导出 BibTeX、删除（可撤销）、AI 重读、**对这几篇一起提问**、查重。
- 键盘：方向键移动、⌘A、Delete、Esc 取消选择。

## 3. 论文问答

**你会看到**：详情栏多一个「提问」页（和现在的卡片并列）；选中多篇时可打开「跨论文提问」窗口（默认最多 10 篇，标记为 P1…Pn）。
- 输入问题 → 回答**逐字流式出现**；带页码引用 `[p. 7]`（多篇时 `[P2 · p. 5]`），点一下就在 App 内的 PDF 阅读器里跳到那一页并高亮引用的句子。
- 中文 / English 回答可切换；「快」（Claude Haiku / GPT‑5.6‑Luna）和「深入」（Sonnet / Terra）一键切换。
- 可以继续追问；答案可「存进笔记」（带页码）。问答历史随论文保存（可重建）。
- 发送前显示预计长度；**每次都由你点击触发，没有后台问答**；可能未发表的稿件先提醒。

**怎么做**：把这篇论文清洗后的全文（太长时按问题挑最相关的页）+ 你的问题交给你订阅的 CLI，模型没有任何工具权限，论文文本按「不可信数据」处理。

## 4. 讲解框：在任何软件里看论文都能用

一个快捷键（建议 **⌃⌥E**，可改）进入「讲解模式」，预览、Acrobat、Skim、浏览器里的 PDF、PaperDeck 自己都能用：

| 触发方式 | 用法 | 需要的权限 |
|---|---|---|
| **框选** | 屏幕轻微变暗，拖一个框，松手即讲解框里的文字 / 公式 / 图 | 屏幕录制 |
| **放大镜** | 按空格切换成一个圆形放大镜跟着鼠标，点一下讲解鼠标下的那一段；⌥+点击讲这张图；双击解释单个术语 | 屏幕录制 |
| **复制即讲** | 选中文字 ⌘C（或 ⌃⇧⌘4 截图到剪贴板），按快捷键 → 讲解 | **无** |
| **右键 › 服务 ›「用 PaperDeck 讲解」** | 选中文字直接讲 | **无** |
| 菜单栏「讲解…」/ 把截图拖到悬浮窗 | | 无 |

**讲解框**：在鼠标旁边弹出的玻璃浮窗，不抢焦点（你的 PDF 软件保持在前台、选区不丢）。
- 答案逐字出现；EN / 中文切换；按钮：**更浅显 / 更专业 / 解释术语 / 讲解这张图 / 翻译**；可继续追问；复制、钉住、**存进这篇论文的笔记（带页码）**；每篇论文保留讲解历史；全程键盘可用，Esc 关闭。
- **自动认出是哪篇论文**：用窗口标题（文件名、arXiv 号）或识别出的文字去本机全文索引匹配；匹配上就把那一页附近的原文一起给 AI，讲得更准。全部在本机完成。
- 公式、图表：本机文字识别（Vision，中英文）效果差或是图时，**直接把截图交给 AI**（两个 CLI 都支持传图片，已在你电脑上确认）。

**内置阅读器（建议 v1 做一个极简版）**：用 PaperDeck 打开 PDF 时，选中文字就能拿到准确文字和页码——不用识别、不用屏幕权限，公式和图按原始清晰度截取；也是问答「点页码跳转」的落脚点（顺带修好现在清单里「从第 N 页开始」不跳页的 bug）。「打开 PDF」默认仍然用预览，不改变你现在的习惯。

## 5. 额度、隐私、权限、电脑负担

- **额度**：查重的前四层、文字识别、认出论文都在本机，**不耗额度**。只有问答、讲解、（可选）AI 查重判定会调用 CLI，而且**每次都是你亲手触发**；默认快速小模型；讲解默认每天上限 50 次，界面显示「今天第 N 次」；额度用尽时和现有解读一样自动暂停。
- **WashU 政策**：他人邮件发来、可能未发表的稿件，以及审稿/投稿类内容，送 AI 前一定先确认；查重的 AI 判定永不处理这类稿件。
- **权限**：只有框选和放大镜需要「屏幕录制」（第一次用时先解释再申请，拒绝也不影响其他方式）；**不需要「辅助功能」权限**。
- **速度**：讲解首字预计 Claude 2.5–5 秒（讲解模式打开时可预先启动一个空闲进程，降到 1–2 秒；空闲 3 分钟自动关闭）；ChatGPT（Codex）不支持逐字输出，约 5–13 秒后整段出现。
- **电脑负担**：不做后台索引；指纹在导入时顺手算（几毫秒）；整库扫描约 2000 篇 4 秒。实施时同时编译的 agent 最多 2–3 个。

## 6. 需要你拍板的问题（括号里是我的建议，回复「全部按建议」即可）

1. **「选取多少篇」的含义**：一次选中 N 篇做批量操作 + 一起提问（**是**）。如果你指别的，请告诉我。
2. **疑似重复（模糊匹配）的论文拖进来时**：先照常出卡片但「暂停」（不排 DDL、不 AI 解读，带「可能重复？」标签并弹决策框）（**建议**）；还是干脆先不入库等你决定？
3. **AI 查重判定**：默认关闭，打开后每天最多 10 次（**建议**）。
4. **讲解默认语言**：**中文讲解 + 保留英文术语**（建议），还是跟随界面用英文？
5. **快捷键**：⌃⌥E 进入框选、空格切换放大镜（**建议**）。
6. **问答默认模型**：默认「快」（Haiku/Luna），需要时点「深入」（**建议**，省额度）；还是默认「深入」？
7. **v1 是否做极简内置阅读器**：**做**（建议）。
8. **一次性真实测试**：实施时需要 ≤6 次很小的真实调用（快速模型）来验证逐字输出和传图片的格式，你同意吗？（**建议同意**；其余全部用模拟 AI 测试，不耗额度）

## 7. 实施顺序与时间（2–3 个 agent 并行，控制电脑负载）

可移植化（已批准）先做完，再按下面顺序；每期都经过「修复 → 审查 → 反证核实」再装到你的电脑上：

| 期 | 内容 | 预计（墙钟时间） |
|---|---|---|
| **第一期** | 查重（本机 1–3 层 + 决策框 + 批量汇总 + 修补充材料/替换 bug）、多选 + 批量操作条 | 约 5–7 小时 |
| **第二期** | 问答（单篇）+ 逐字输出的 AI 通道 + 极简内置阅读器（页码跳转、选中即问） | 约 5–7 小时 |
| **第三期** | 讲解框：复制即讲 / 服务菜单 → 框选 / 放大镜 → 认出论文 → 讲解历史、存笔记 | 约 6–8 小时 |
| **第四期（可选）** | 本机语义查重、整库扫描与合并工具、AI 查重判定、跨论文问答、术语表等阅读辅助 | 约 4–6 小时 |

（第一期和第二期互相独立，若你更想先用上问答/讲解，也可以调换顺序。）

## 8. 可选的阅读辅助（不在估时内，之后按需加）

- **个人术语表**：「解释术语」的结果自动收进可搜索的中英双语术语表，阅读器里已知术语加下划线。
- **图表逐步讲解**：「带我看 Fig. 3」，按小图逐个讲。
- **问题 → 清单**：你追问过的问题可以一键变成清单条目。
- **下一篇读什么**：从讲解过的段落里抽出引用文献，标出「已在库中 / 按 DOI 添加」。
- **读完总结**：标记「已读」时把你钉住的讲解汇总成一页笔记。
